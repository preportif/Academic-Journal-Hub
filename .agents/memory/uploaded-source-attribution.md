---
name: Uploaded source attribution
description: How to present uploaded publication files whose internal journal label differs from the portal brand.
---

When a user explicitly approves adding an uploaded publication file whose internal journal label differs from the portal’s journal, keep the record visible but show the exact source label on the article card and detail page. Do not silently rewrite the source attribution.

**Why:** The uploaded PDF may be useful to the user while still containing bibliographic information that conflicts with the portal’s branding.

**How to apply:** Preserve the file’s title, authors, abstract, keywords, and source label as provided; add a concise notice explaining that the file was included at the user’s request.
